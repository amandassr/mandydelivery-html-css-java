# Mandy Delivery

Projeto final do curso **Programação Web Tech para Manas**, realizado no SENAI Vitória.

O projeto foi criado para praticar os fundamentos do desenvolvimento web por meio da construção de uma interface de delivery.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Aprendizados

- Estruturação semântica de páginas
- Organização visual com CSS
- Interações básicas com JavaScript
- Planejamento e apresentação de um projeto web

Este repositório representa uma etapa inicial da minha formação em tecnologia e desenvolvimento de interfaces.
