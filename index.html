Sobre o projeto

Do primeiro site a uma experiência funcional

O Mandy Delivery nasceu como projeto final do curso Programação Web Tech para Manas, no SENAI Vitória. Esta evolução mantém a ideia original e adiciona uma experiência completa de catálogo e carrinho usando apenas HTML, CSS e JavaScript.

Projeto educacional desenvolvido por Amanda Ribeiro.

• Consuma com moderação. Venda proibida para menores de 18 anos.
